# Recipe configuration

Recipe files live under `plugins/VcustomCrafts/recipes/`. Nested folders are allowed.

## Shaped recipe

```yaml
id: ruby_blade
enabled: true
name: '<red><bold>Ruby Blade</bold>'
type: SHAPED
shape:
  - ' R '
  - ' R '
  - ' S '
ingredients:
  R:
    saved-item: ruby
    amount: 1
    match-mode: EXACT
  S:
    material: STICK
    amount: 1
    match-mode: MATERIAL
result:
  saved-item: ruby_blade
  amount: 1
requirements:
  permission: vcustomcrafts.craft
cost:
  experience-levels: 3
success-chance: 100.0
```

## Shapeless recipe

```yaml
id: mixed_dust
type: SHAPELESS
ingredients:
  - material: GLOWSTONE_DUST
    amount: 2
  - material: REDSTONE
    amount: 4
result:
  material: BLAZE_POWDER
  amount: 1
```

## Item sources

An ingredient or result may use one of:

```yaml
material: DIAMOND
saved-item: custom_gem
snapshot: '<base64 generated by the GUI>'
tag: minecraft:logs
provider: my_item_plugin
id: namespace:item_id
```

`provider` works after another plugin registers a `CustomItemProvider` through the public API. For unknown item plugins, capture the real item with `/vcc item save <id>`; that path requires no dedicated integration.

## Matching

- `MATERIAL`: only the Material and required amount are checked.
- `EXACT`: Bukkit/Paper `ItemStack#isSimilar` is used, preserving custom metadata represented in the stack.
- `ADVANCED`: select fields under `match`.

```yaml
match-mode: ADVANCED
match:
  name: true
  lore: true
  custom-model-data: true
  enchantments: true
  pdc: true
  damage: false
```

## Alternatives

```yaml
ingredients:
  A:
    amount: 1
    match-mode: MATERIAL
    any-of:
      - material: OAK_LOG
      - material: SPRUCE_LOG
      - tag: minecraft:logs
```

## Consumption behavior

```yaml
# Catalyst: required but kept
consume: false
```

```yaml
# Damage a tool instead of removing it
consume-mode: DAMAGE
damage-amount: 1
```

```yaml
# Remove the ingredient and return another item
consume-mode: RETURN
return-item:
  material: BUCKET
  amount: 1
```

## Failure behavior

```yaml
success-chance: 75.0
failure:
  consume-ingredients: true
```

Invalid recipe files are reported with their relative path and do not crash the entire plugin.
