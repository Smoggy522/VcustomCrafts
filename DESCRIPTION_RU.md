# Краткое описание

**VcustomCrafts — создавайте безопасные shaped и shapeless-рецепты практически из любых предметов.** Сохраняйте ванильные и кастомные `ItemStack` из ItemsAdder, Oraxen, Nexo и других плагинов прямо из руки, собирайте рецепт в игровом GUI и используйте точное сравнение имени, lore, CustomModelData, enchantments и PDC. В комплекте — книга рецептов, катализаторы, повреждение инструментов, возврат тары и проверяемые автообновления через GitHub Releases.

# Полное описание

## VcustomCrafts — Use ANY ItemStack as an Ingredient

VcustomCrafts — конструктор кастомных крафтов для Paper и Purpur 1.21.x на Java 21. Он создан для серверов, которым недостаточно обычных рецептов Minecraft, но не хочется писать отдельный Java-плагин для каждого нового предмета.

Главная идея проста: если сторонний плагин выдаёт предмет как обычный Bukkit/Paper `ItemStack`, администратор может взять этот предмет в руку, сохранить его командой и использовать как ингредиент или результат. Специальная интеграция не обязательна: VcustomCrafts сохраняет снимок предмета вместе с доступными Bukkit метаданными и сравнивает будущие предметы с ним.

### Создание рецепта в игре

Введите `/vcc editor legendary_sword shaped`, разложите ингредиенты в сетке 3×3, положите результат и нажмите Save. Плагин создаст YAML-файл с точными снимками предметов, проверит его и сразу загрузит рецепт. Предметы администратора после закрытия редактора возвращаются.

### Гибкое сравнение предметов

Для каждого ингредиента можно выбрать режим:

- MATERIAL — проверяется тип предмета и количество;
- EXACT — точное сравнение `ItemStack` через Paper/Bukkit;
- ADVANCED — отдельно настраиваются имя, lore, CustomModelData, enchantments, PDC и damage.

Поддерживаются сохранённые предметы, встроенные snapshots, Minecraft item tags, несколько альтернатив для одного слота и расширяемый provider API для других разработчиков.

### Больше, чем простое удаление ингредиента

Ингредиент может расходоваться, оставаться катализатором, терять прочность или возвращать другой предмет. Например, Magic Hammer остаётся в сетке и повреждается, а Water Bucket превращается в пустое ведро.

Можно добавить permission, стоимость в уровнях опыта, шанс успеха и расход ингредиентов при неудаче.

### Защита крафта

VcustomCrafts перехватывает собственные shaped/shapeless-рецепты и выполняет их как проверяемую операцию: рассчитывает доступное количество крафтов, проверяет курсор и свободные слоты, создаёт снимок матрицы и инвентаря, применяет изменения и восстанавливает состояние при ошибке. Небезопасные number-key/double-click действия на результате блокируются; shift-click ограничен настраиваемым максимумом.

### Обновления через GitHub

Плагин проверяет Releases репозитория `Smoggy522/VcustomCrafts`, находит JAR по строгому шаблону имени, ограничивает размер, сверяет SHA‑256 и помещает проверенный файл в update-папку Paper. Установка выполняется при следующем полном перезапуске; удалённые команды и автоматический рестарт не используются. Поддерживаются публичные и приватные репозитории — токен для приватного репозитория передаётся только через переменную окружения.

### Возможности версии 1.0

- Paper/Purpur 1.21.x и Java 21;
- shaped и shapeless-рецепты;
- GUI-редактор и `/recipes`;
- захват практически любого ItemStack из руки;
- MATERIAL / EXACT / ADVANCED matching;
- alternatives и Minecraft tags;
- consume / keep / damage / return item;
- permissions, уровни XP и шанс успеха;
- безопасный normal-click и shift-click;
- транзакционная перезагрузка рецептов;
- английская и русская локализация;
- developer provider API;
- GitHub Actions и проверяемые автообновления.

Furnace, smithing, stonecutter, Vault, базы данных, unlock-система и custom stations относятся к следующим этапам и не заявлены как готовые функции версии 1.0.
